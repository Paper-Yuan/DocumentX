# 历史归档

以下是 SafeDrop v1.0 – v1.2 开发期留下的内部记录：优化计划、阶段报告、测试记录。
它们**不是文档**，不描述当前代码，也不会随版本更新。

保留是为了可追溯：功能为什么那样设计、当时测过什么。

归档内的路径是重命名之前的布局：

| 归档中写作 | 现在位于 |
|:---|:---|
| `computer-design/` | `apps/desktop/` |
| `android-design/` | `apps/android/` |
| 根目录 `Launcher.cs` | `apps/desktop/installer/Launcher.cs` |
| 根目录 `test_*.js` | `test/e2e/*.js` |

当前事实一律以 `README.md`、`CHANGELOG.md` 和代码本身为准；三者与这里冲突时，以三者为准。
